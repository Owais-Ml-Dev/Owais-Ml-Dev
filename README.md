### 🚀 Featured Engineering Projects

#### 🧠 [GPT Style Language Model from Scratch](https://github.com/Owais-Ml-Dev/GPT-from-Scratch/tree/main)
Implemented a decoder only transformer to dissect the internal mechanics of generative AI. 
* **Technical Depth:** Developed multi head causal self attention, learned positional encodings, and residual connections without relying on high level transformer abstractions.
* **Optimization:** Fine tuned training stability using AdamW and implemented diverse inference strategies including Temperature and Top K sampling.

#### 🎙️ [Speech Emotion Recognition System](https://github.com/Owais-Shaikh-0786/Speech-Emotion-Recognition-with-librosa)
Built an end to end signal processing and classification pipeline to detect emotional states in human speech.
* **Feature Engineering:** Extracted Mel Frequency Cepstral Coefficients (MFCCs), Zero Crossing Rate, and Root Mean Square energy using Librosa.
* **Architecture:** Conducted comparative analysis between CNNs for spatial acoustic textures and LSTMs for modeling temporal emotional flow.

#### 👁️ [Real Time Drowsiness Detection](https://github.com/Owais-Shaikh-0786/Drowsiness-Detection-System)
Designed a safety critical computer vision system to monitor driver alertness and mitigate road accidents.
* **Core Logic:** Leveraged OpenCV and Haar Cascades for precise facial landmark tracking.
* **Deployment:** Integrated a deep learning classification head with Streamlit to provide a seamless, real time monitoring interface.

#### 📅 [AI Powered Attendance System](https://github.com/Owais-Shaikh-0786/Attendance_System)
Developed a scalable automated logging system using real time face recognition and cloud synchronization.
* **Integration:** Coupled OpenCV with the face recognition library to generate biometric encodings, storing data in Firebase for persistent, real time access.
